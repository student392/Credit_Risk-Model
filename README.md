# **Credit Risk Model**<br>
A machine learning–based Credit Risk Prediction system designed to assess the likelihood of loan default using historical financial and customer data.

## **🧠 Overview**<br>
This project focuses on building a predictive model that helps financial institutions evaluate credit risk more accurately. By analyzing customer and loan-related features, the model predicts whether an applicant is likely to default, supporting data-driven decision-making in lending processes. The project demonstrates practical applications of data preprocessing, feature engineering, and machine learning classification techniques.

## **🚀 Features**<br>
✅ Data cleaning and preprocessing<br>
✅ Exploratory Data Analysis (EDA)<br>
✅ Feature selection and scaling<br>
✅ Machine learning model training<br>
✅ Model evaluation using performance metrics<br>
✅ Credit risk prediction (default / non-default)<br>

## **🧱 Project Structure**<br>

├── models/            # Trained model files <br> 
├── src/               # Core source code  <br>
├── requirements.txt   # Python dependencies  <br>
└── README.md          # Project documentation<br>

## **⚙️ Installation**<br>
Install required dependencies:<br>
pip install -r requirements.txt<br>

## **▶️ Usage**<br>
Run the Jupyter notebook to explore data and train the model:<br>
jupyter notebook<br>
Follow the steps inside the notebook for preprocessing, training, and evaluation.<br>

## **📊 Model Evaluation**<br>
The model is evaluated using standard classification metrics such as accuracy, precision, recall, and confusion matrix to measure credit risk prediction performance.<br>
